# Foreground Service 起動失敗対応

調査対象の Google Play クラッシュレポートを基に、Foreground Service の起動または前景化が
拒否された場合にアプリをクラッシュさせず、安全に停止・復旧できるようにする。

## 背景

`scripts/play-reporting/output/reports-20260728-023538.json` には、versionCode 89 の
`ForegroundServiceStartNotAllowedException` が 5 ErrorReport、3 Issue 含まれている。
ErrorReport は同一内容が集約されるため、5件は実際のクラッシュ回数を表さない。

発生箇所は次の2経路。

| 経路 | Reports | 発生箇所 |
| --- | ---: | --- |
| Service の起動要求が拒否される | 1 | `Context.startForegroundService()` |
| 起動済み Service の前景化が拒否される | 4 | `Service.startForeground()` |

前景化失敗4件はすべて Android 16（API 36）で、Pixelを含む複数メーカーに発生している。
起動要求失敗1件は Android 15（API 35）のHonor端末で、`BOOT_COMPLETED` から発生している。

versionCode 89 からリリース予定の versionCode 92 まで、該当する起動処理と前景化処理に変更はなく、
現在の `dev` ブランチも同じクラッシュ条件を持つ。

## 目標

- `Context.startForegroundService()` と `Service.startForeground()` の拒否を処理する
- 前景化できなかった Service をバックグラウンドで動作させ続けない
- 前景化成功前と前景化失敗後に、非同期callbackから音量・Alarm・保存状態を変更しない
- 起動失敗時に保存済みのミュート状態を破棄しない
- `IsLive` とQuick Settings Tileの表示を実際のService状態に一致させる
- 通知が許可されている場合、ユーザー操作から再起動できる通知へフォールバックする
- API 21のサポートとAndroidX依存ゼロを維持する

## 対応方針

### 1. Service起動要求の例外処理

対象: `Compat.java`

`startForegroundService(Context, Intent)` を、成功可否を返す
`tryStartForegroundService(Context, Intent)` に変更する。

- API 31以降は `ForegroundServiceStartNotAllowedException` を捕捉して `false` を返す
- API 26～30は従来どおり `Context.startForegroundService()` を呼ぶ
- API 21～25は従来どおり `Context.startService()` を呼ぶ
- 例外型への参照は `@RequiresApi(Build.VERSION_CODES.S)` のprivateメソッドに隔離する
- Intent、API level、例外型、例外メッセージをthrowable付きでLogcatへ記録する
- 同じ内容とスタックトレースを `DiagnosticsLogger.Instance` にも送り、有効な診断出力先へ記録する
- Manifest不備を示す `SecurityException` など、今回と異なる例外は握りつぶさない

同じクラスに `tryStartForeground(Service, int, Notification)` を追加し、
`Service.startForeground()` の `ForegroundServiceStartNotAllowedException` も同じ方式で処理する。

`tryStartForegroundService()` の `true` は「起動要求をOSが受理した」ことだけを表す。
Serviceの生成、`onStartCommand()` の完了、前景化成功までは保証しない。

### 2. 起動結果の呼び出し元への伝播

対象: `IntentUtility.java`

次のメソッドの戻り値を `void` から `boolean` に変更する。

- `start()`
- `stop()`
- `stopUntilScreenOff()`
- `switching()`
- `applySettings()`
- `reboot()`

既存のActivityとTileはユーザー操作による起動経路であり、戻り値を無視する。バックグラウンド起動元である
`DNSReceiver` は戻り値を確認し、起動要求がその場で拒否された場合に復旧通知を表示する。
起動要求が受理された後の前景化結果は同期的に呼び出し元へ返せないため、Service側で処理する。
`shutdown()` はActivityから既存Serviceへ停止命令を送る処理なので変更しない。

### 3. Boot・パッケージ更新時のフォールバック

対象: `DNSReceiver.java`

`BOOT_COMPLETED` と `MY_PACKAGE_REPLACED` からの起動結果を確認する。失敗した場合は既存の
再起動通知を表示し、通知タップによるユーザー操作から再起動できるようにする。

`showRebootNotification(Context)` は、通知を表示できたかを返すpackage-privateな
`tryShowRebootNotification(Context)` に変更し、`DNSService` からも利用する。新しい通知クラスへの
分割は今回の修正範囲に含めない。

Android 13以降で `POST_NOTIFICATIONS` が拒否されている場合、通常の復旧通知は表示できない。
通知表示はbest effortとし、権限拒否、アプリ通知無効、復旧通知channel無効、通知作成・投稿時の
`RuntimeException` を呼び出し元へ送出しない。失敗理由とthrowableを診断ログへ記録し、`false` を返す。
Service内では停止処理を通知表示より先に成立させ、通知失敗によって停止処理が飛ばされないようにする。
起動要求自体が拒否された場合は、ServiceとTileを明示的に非稼働状態へ更新してから通知を試みる。
この場合の復旧経路は、ユーザーがランチャーまたはQuick Settings Tileからアプリを起動する操作となる。

### 4. Serviceを副作用より先に前景化

対象: `DNSService.java`

`onStartCommand()` ではIntent actionを確定した後、音量変更、状態保存、Alarm設定より先に
初期通知を作成して `tryStartForeground()` を呼ぶ。処理順は次のとおりとする。

1. Intentからcommandを確定する。null Intentは `ACTION_REBOOT` とする
2. `ACTION_SHUTDOWN` なら前景化せず明示停止処理へ進む
3. 未前景化なら現在のService内状態から初期通知を構築し、前景化を試みる
4. 失敗なら失敗時停止処理を行い、commandを実行しない
5. 成功後に `IsLive = true` とし、commandを実行する

- `ACTION_SHUTDOWN` は前景化せず、従来どおりServiceを停止する
- `IsLive = true` は前景化成功後に設定する
- `IsLive == true` は、このServiceインスタンスが前景化に成功済みで稼働中であることを表す
- `IsLive == true` の同じServiceインスタンスでは `startForeground()` を再実行しない
- 後続の起動要求で前景化に成功した場合は、失敗状態を解除して通常処理へ戻す
- sticky再作成でIntentがnullの場合は、従来どおり `ACTION_REBOOT` として処理する

Foreground Serviceは起動後速やかに前景化する必要がある。現在は `update()` の終盤まで
前景化しないため、処理順を変更して許可状態が失効する可能性とタイムアウトの余地を減らす。

### 5. 通知の作成と更新を分離

対象: `DNSService.java`

現在の `createNotification(boolean)` を次の責務に分割する。

- `buildStatusNotification(boolean)` — `Notification` の構築
- `updateStatusNotification(boolean)` — 前景化済みServiceの通知更新

初回だけ `tryStartForeground()` に構築済み通知を渡す。以後の状態変更では
`NotificationManager.notify()` を使い、`startForeground()` を繰り返さない。
`updateStatusNotification()` は `IsLive == true` の場合だけ通知を更新する。

Serviceの `onCreate()` ではBroadcastReceiver、Bluetooth、AudioDevice、AudioPlaybackのcallbackを
登録するため、前景化前や失敗後にもcallbackが届く可能性がある。callbackの入口では一律に
`IsLive` を確認してreturnせず、ログ記録やBluetooth profile proxyの保存は行う。`update()` は通常どおり
呼び出し、`update()` 自体のガードで通知、音量、WakeLock、Alarm、Tileへの副作用を防ぐ。
`start()`、`restoreVolume()`、`backupVolume()` は各メソッドの冒頭で `IsLive` を確認し、前景化前の
呼び出しでは本体を実行しない。イベント側には個別の `IsLive` 条件を追加しない。
前景化前にだけ発生したedge eventは繰り越さず、前景化成功後に既存commandから到達する `update()` で
現在のミュート状態を反映する。このためのpending flagは追加しない。

### 6. 前景化失敗時の停止処理

対象: `DNSService.java`

`tryStartForeground()` が `false` を返した場合は、コマンドによる状態変更を開始せず、
`onStartCommand()` 内で次の処理を行って `START_NOT_STICKY` を返す。

1. 診断ログへ失敗を記録する
2. `tryStopService(startId)` で共通終了処理を行う
3. 停止が成立した場合だけ、例外非送出の復旧通知を試みる
4. `onStartCommand()` から `START_NOT_STICKY` を返す

`tryStopService(startId)` は `ACTION_SHUTDOWN` と前景化失敗の2か所だけから呼ぶ。
`stopSelfResult(startId)` が `true`、つまり対象が最新のstart requestでServiceが停止される場合だけ、
`IsLive = false`、定期再起動Alarm解除、Quick Settings Tile更新を行う。保存状態の削除、Toast、
再起動通知など終了理由固有の処理と、`START_NOT_STICKY` の返却は共通メソッドに含めない。
停止成立時は `true`、より新しいstart requestが存在して停止しない場合は `false` を返す。
`false` の場合は後続requestが前景化を再試行するため、早すぎる復旧通知は表示しない。後続requestも
失敗し、それが最新のrequestとして停止できた時点で復旧通知を表示する。

例外を捕捉した後もServiceを継続すると、前景化期限超過による別のクラッシュや、OSによる
プロセス終了につながる。失敗時はServiceを終了し、自動再作成は行わない。ただし、失敗処理中に
より新しいstart requestが到着済みなら `stopSelfResult(startId)` は `false` を返してServiceを止めない。
既に前景化済みなら `IsLive == true` を維持し、前景化失敗後なら `IsLive == false` のまま後続commandで
前景化を再試行する。

### 7. 保存状態とライフサイクルの整合

対象: `DNSService.java`

現在の `onDestroy()` は常に `clearState()` を実行するため、前景化失敗後にServiceを停止すると
復旧に必要な保存状態も消える。保存状態を削除する条件をライフサイクル終了一般ではなく、
ユーザーの明示的な `ACTION_SHUTDOWN` が実際にServiceを停止できた場合に限定する。

- `tryStopService(startId)` が `true` を返した `ACTION_SHUTDOWN` だけで `clearState()` を呼ぶ
- 同じ明示停止成功時に `cancelTimer()` を呼び、一時停止用の `ACTION_START` Alarmも解除する
- `tryStopService(startId)` が `false` の場合は、後続commandを優先して保存状態を削除しない
- `onDestroy()` から `clearState()` を削除し、ライフサイクル終了と状態削除を分離する

`onDestroy()` では理由にかかわらず `IsLive = false` を設定し、Tileへ非稼働状態を通知する。
これにより、前景化失敗や予期しないライフサイクル終了では状態を保持し、ユーザーが明示的に
停止した場合だけ従来どおり保存状態を削除する。

明示停止時の `cancelTimer()` は `tryStopService(startId) == true` の分岐内だけで実行する。前景化失敗や
より新しいstart requestが存在する場合は、一時停止からの復旧に必要なAlarmを維持する。

### 8. 拒否経路の決定的なテスト

対象: `Compat.java`、`ForegroundServiceFailureTest.java`

実端末やエミュレータで `ForegroundServiceStartNotAllowedException` を安定して再現できない場合でも、
例外経路をコードレビューだけで済ませない。`Compat` のOS呼び出し部分をpackage-privateな関数型interfaceで
差し替えられるようにし、debugビルドのandroidTestから起動要求拒否と前景化拒否を強制する。

- test operationがnullの通常時は従来どおりAndroid APIを直接呼ぶ。API 26メソッド参照のstatic lambdaは
  API 21でのクラス初期化リスクを増やすため保持しない
- test setterは `BuildConfig.DEBUG` 以外では例外にし、各test終了後に必ずnullへ戻す
- operation参照はandroidTestとService main thread間で共有するため `volatile` とする
- 起動要求拒否が `false` を返すことを確認する
- 前景化拒否後に `IsLive == false`、保存状態維持、Service停止となることを確認する
- 復旧通知の作成・投稿が例外になっても呼び出し元へ送出しないことを確認する
- 一時停止Alarm設定後に明示停止し、期限後もServiceが再起動しないことを機能確認する

## 具体的な実装コード

以下は実装時の骨格とする。既存のBuilder設定、各commandの処理本体、リソース解放処理など、
今回変更しないコードは省略している。

### `Compat.java`

API 31以降でだけ例外型を参照するprivateメソッドへ分岐する。`SecurityException`、
`MissingForegroundServiceTypeException` など、対象外の例外はそのまま呼び出し元へ送出する。
捕捉対象の例外はLogcatだけでなく `DiagnosticsLogger` にも送り、ファイル出力またはcallbackが
有効ならスタックトレースを含めて保存する。ここではLoggerのファイル初期化やToast表示は行わない。

```java
import android.app.ForegroundServiceStartNotAllowedException;
import android.app.Service;
import android.util.Log;

final class Compat {
    private static final String TAG = "Compat";

    @FunctionalInterface
    interface ForegroundServiceStartOperation {
        void start(Context context, Intent intent);
    }

    @FunctionalInterface
    interface ForegroundPromotionOperation {
        void start(Service service, int notificationId, Notification notification);
    }

    private static volatile ForegroundServiceStartOperation foregroundServiceStartOperationForTest;
    private static volatile ForegroundPromotionOperation foregroundPromotionOperationForTest;

    static boolean tryStartForegroundService(Context context, Intent intent) {
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.S) {
            return tryStartForegroundServiceApi31(context, intent);
        }
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
            context.startForegroundService(intent);
        } else {
            context.startService(intent);
        }
        return true;
    }

    @RequiresApi(Build.VERSION_CODES.S)
    private static boolean tryStartForegroundServiceApi31(Context context, Intent intent) {
        try {
            ForegroundServiceStartOperation operation = foregroundServiceStartOperationForTest;
            if (operation == null) {
                context.startForegroundService(intent);
            } else {
                operation.start(context, intent);
            }
            return true;
        } catch (ForegroundServiceStartNotAllowedException ex) {
            logForegroundServiceStartFailure("startForegroundService rejected: sdk=" + Build.VERSION.SDK_INT + " intent=" + intent + " exception=" + ex.getClass().getName() + ": " + ex.getMessage(), ex);
            return false;
        }
    }

    static boolean tryStartForeground(Service service, int notificationId, Notification notification) {
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.S) {
            return tryStartForegroundApi31(service, notificationId, notification);
        }
        service.startForeground(notificationId, notification);
        return true;
    }

    @RequiresApi(Build.VERSION_CODES.S)
    private static boolean tryStartForegroundApi31(Service service, int notificationId, Notification notification) {
        try {
            ForegroundPromotionOperation operation = foregroundPromotionOperationForTest;
            if (operation == null) {
                service.startForeground(notificationId, notification);
            } else {
                operation.start(service, notificationId, notification);
            }
            return true;
        } catch (ForegroundServiceStartNotAllowedException ex) {
            logForegroundServiceStartFailure("startForeground rejected: sdk=" + Build.VERSION.SDK_INT + " service=" + service.getClass().getName() + " exception=" + ex.getClass().getName() + ": " + ex.getMessage(), ex);
            return false;
        }
    }

    private static void logForegroundServiceStartFailure(String message, RuntimeException ex) {
        Log.w(TAG, message, ex);
        DiagnosticsLogger.Instance.Log(TAG, message + "\n" + Log.getStackTraceString(ex));
    }

    static void setForegroundServiceStartOperationForTest(ForegroundServiceStartOperation operation) {
        if (!BuildConfig.DEBUG) throw new UnsupportedOperationException("debug builds only");
        foregroundServiceStartOperationForTest = operation;
    }

    static void setForegroundPromotionOperationForTest(ForegroundPromotionOperation operation) {
        if (!BuildConfig.DEBUG) throw new UnsupportedOperationException("debug builds only");
        foregroundPromotionOperationForTest = operation;
    }

    static void resetForegroundOperationsForTest() {
        if (!BuildConfig.DEBUG) throw new UnsupportedOperationException("debug builds only");
        foregroundServiceStartOperationForTest = null;
        foregroundPromotionOperationForTest = null;
    }
}
```

### `DNSReceiver.java`

同期的な起動要求拒否だけをReceiver側で処理する。起動要求が受理された後の前景化失敗は
`DNSService` 側で処理する。`NotificationChannel` をimportし、通知権限、アプリ通知設定、復旧通知channelを
確認する。通知処理全体の `RuntimeException` を捕捉し、ログを残して `false` を返す。

```java
case Intent.ACTION_BOOT_COMPLETED: {
    Log.d(TAG, "ACTION_BOOT_COMPLETED");
    if (!IntentUtility.start(context)) {
        Log.w(TAG, "foreground service start request rejected after boot");
        markServiceInactiveAfterRejectedStart();
        tryShowRebootNotification(context);
    }
    break;
}
case Intent.ACTION_MY_PACKAGE_REPLACED: {
    Log.d(TAG, "ACTION_MY_PACKAGE_REPLACED");
    if (!IntentUtility.reboot(context, "ACTION_MY_PACKAGE_REPLACED")) {
        Log.w(TAG, "foreground service start request rejected after package replacement");
        markServiceInactiveAfterRejectedStart();
        tryShowRebootNotification(context);
    }
    break;
}
```

起動要求拒否ではServiceが生成されないため、現在状態とTileを明示的に非稼働へ揃える。

```java
private static void markServiceInactiveAfterRejectedStart() {
    DNSService.IsLive = false;
    IntentUtility.setTileInactive();
}
```

`DNSService` からも呼べるよう、通知メソッドをpackage-privateにする。既存のBuilder設定は維持しつつ、
通知を表示できない条件と例外を処理する。

```java
static boolean tryShowRebootNotification(Context context) {
    try {
        if (!PermissionUtility.isPostNotificationsGranted(context)) {
            logRebootNotificationFailure("POST_NOTIFICATIONS is not granted", null);
            return false;
        }

        NotificationManager notificationManager =
                Compat.getSystemService(context, NotificationManager.class);
        if (notificationManager == null) {
            logRebootNotificationFailure("NotificationManager is null", null);
            return false;
        }

        NotificationInfo.createNotificationChannels(context, notificationManager);

        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.N
                && !notificationManager.areNotificationsEnabled()) {
            logRebootNotificationFailure("app notifications are disabled", null);
            return false;
        }

        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
            NotificationChannel channel =
                    notificationManager.getNotificationChannel(NotificationInfo.ID_REBOOT);
            if (channel == null
                    || channel.getImportance() == NotificationManager.IMPORTANCE_NONE) {
                logRebootNotificationFailure("reboot notification channel is disabled", null);
                return false;
            }
        }

        int immutableFlag =
                Build.VERSION.SDK_INT >= Build.VERSION_CODES.M
                        ? PendingIntent.FLAG_IMMUTABLE
                        : 0;
        Context applicationContext = context.getApplicationContext();
        if (applicationContext == null) applicationContext = context;

        PendingIntent startIntent =
                PendingIntent.getActivity(
                        applicationContext,
                        NotificationInfo.REQUEST_CODE_REBOOT,
                        new Intent(applicationContext, MainActivity.class),
                        PendingIntent.FLAG_CANCEL_CURRENT | immutableFlag);
        Notification.Builder builder =
                Compat.createNotificationBuilder(context, NotificationInfo.ID_REBOOT)
                        .setSmallIcon(R.drawable.ic_volume_up_black_24dp)
                        .setContentTitle(context.getText(R.string.notification_reboot_content_title))
                        .setContentText(context.getText(R.string.notification_reboot_content_text))
                        .setColor(0xFF5419)
                        .setPriority(Notification.PRIORITY_HIGH)
                        .setVisibility(Notification.VISIBILITY_PUBLIC)
                        .setContentIntent(startIntent);

        notificationManager.notify(NotificationInfo.REQUEST_CODE_REBOOT, builder.build());
        return true;
    } catch (RuntimeException ex) {
        logRebootNotificationFailure("failed to show reboot notification", ex);
        return false;
    }
}

private static void logRebootNotificationFailure(String message, Throwable ex) {
    if (ex == null) {
        Log.w(TAG, message);
    } else {
        Log.w(TAG, message, ex);
    }
    DiagnosticsLogger.Instance.Log(
            TAG,
            ex == null ? message : message + "\n" + Log.getStackTraceString(ex));
}
```

### `DNSService.java`

前景化状態には既存の `IsLive` を使用する。保存状態の削除も停止結果から直接判断するため、
新しい状態フラグは追加しない。

`onStartCommand()` は、commandを確定した直後に明示停止を分岐し、それ以外は初回commandの
副作用より前に前景化する。

```java
@Override
public int onStartCommand(Intent intent, int flags, int startId) {
    DiagnosticsLogger logger = Logger;
    if (logger != null) logger.Log(TAG, "onStartCommand flags:" + flags + " id:" + startId);

    String command = intent != null ? intent.getAction() : null;
    if (logger != null) logger.Log(TAG, "command:" + command);
    if (command == null) {
        if (logger != null) logger.Log(TAG, "command is null, reboot");
        command = ACTION_REBOOT;
    }

    if (ACTION_SHUTDOWN.equals(command)) {
        if (logger != null) logger.Log(TAG, "shutdown");
        if (this.tryStopService(startId)) {
            this.cancelTimer();
            this.clearState();
            Toast.makeText(this.getApplicationContext(), R.string.stopped, Toast.LENGTH_SHORT).show();
        }
        return START_NOT_STICKY;
    }

    if (!IsLive) {
        Notification notification = this.buildStatusNotification(this.muteEnabled);
        if (!Compat.tryStartForeground(this, NotificationInfo.REQUEST_CODE_STATUS, notification)) {
            if (logger != null) logger.Log(TAG, "startForeground rejected; stop service");
            boolean stopped = this.tryStopService(startId);
            if (stopped) {
                DNSReceiver.tryShowRebootNotification(this);
            } else if (logger != null) {
                logger.Log(TAG, "newer start request exists; retry foreground promotion");
            }
            return START_NOT_STICKY;
        }
        IsLive = true;
    }

    switch (command) {
        case ACTION_START: {
            this.start();
            break;
        }
        case ACTION_SWITCH: {
            if (this.muteEnabled) {
                this.stop(new Date(0), true);
            } else {
                this.start();
            }
            break;
        }
        case ACTION_STOP: {
            this.stop(new Date(intent.getLongExtra(DISABLE_TIME_NAME, 0)), false);
            break;
        }
        case ACTION_STOP_UNTIL_SCREEN_OFF: {
            this.stop(new Date(0), true);
            break;
        }
        case ACTION_APPLY_SETTINGS: {
            this.applySettings();
            this.update();
            break;
        }
        case ACTION_REBOOT: {
            if (intent != null && logger != null) {
                logger.Log(TAG, "reason: " + intent.getStringExtra(ACTION_REBOOT_EXTRA_REASON));
            }
            this.restoreState();
            this.update();
            break;
        }
        default: {
            if (logger != null) logger.Log(TAG, "unknown command");
            break;
        }
    }

    this.setRebootTimer();
    return START_STICKY;
}
```

前景化失敗時はcommandを実行せず、永続状態にも触れない。`tryStopService()` は終了操作だけを担当し、
Tile更新はガード付きの `update()` を経由せず明示的に非稼働状態を通知する。

```java
private boolean tryStopService(int startId) {
    if (!this.stopSelfResult(startId)) return false;

    IsLive = false;
    this.cancelRebootTimer();
    IntentUtility.setTileInactive();
    return true;
}
```

```java
private Notification buildStatusNotification(boolean enabled) {
    NotificationInfo.createNotificationChannels(this, this.notificationManager);

    Notification.Builder builder =
            Compat.createNotificationBuilder(this, NotificationInfo.ID_STATUS)
                    .setSmallIcon(enabled ? R.drawable.ic_volume_off_black_24dp : R.drawable.ic_volume_up_black_24dp)

                    .setOngoing(true)
                    .setPriority(Notification.PRIORITY_LOW)
                    .setVisibility(Notification.VISIBILITY_PUBLIC)
                    .setContentIntent(enabled ? this.disableIntent : this.startIntent)
                    .setDeleteIntent(this.closeNotificationIntent);

    if (enabled) {
        builder.addAction(new Notification.Action(R.drawable.ic_noisy, this.getResources().getString(R.string.notification_action_untilScreenOff), this.stopUntilScreenOffIntent));
    } else {

    }
```

`update()`、`start()`、`restoreVolume()`、`backupVolume()` の各メソッド冒頭にガードを置く。
callbackの入口やイベント側では `IsLive` を確認せず、各メソッドをそのまま呼び出す。

```java
private void update(boolean forceMute) {
    DiagnosticsLogger logger = Logger;
    if (!IsLive) {
        if (logger != null) logger.Log(TAG, "skip update before foreground start");
        return;
    }

    if (logger != null) logger.Log(TAG, "update forceMute:" + forceMute);

    if (this.muteEnabled) {
        this.mute(forceMute);
        if (this.wakeLock.isHeld()) {
            if (logger != null) logger.Log(TAG, "release wake lock");
            this.wakeLock.release();
        }
    } else {
        if (this.restoreVolume) {
            this.restoreVolume();
        }
        if (this.keepScreenOn && !this.wakeLock.isHeld()) {
            if (logger != null) logger.Log(TAG, "acquire wake lock");
            this.wakeLock.acquire();
        }
    }

    this.cancelTimer();

    long startTime = this.disableTime;
    if (startTime > 0) {
        if (logger != null) logger.Log(TAG, "set timer: " + this.disableTimeString);
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.M) {
            this.alarmManager.setAndAllowWhileIdle(AlarmManager.RTC, startTime, this.startIntent);
        } else {
            this.alarmManager.set(AlarmManager.RTC, startTime, this.startIntent);
        }
    }

    this.updateStatusNotification(this.muteEnabled);
    this.responseStateToTile();
}
```

`start()` は状態の永続化、Audio Focus要求、Toast表示を行うため、`update()` のガードとは別に
メソッド自身をガードする。

```java
private void start() {

    if (logger != null) logger.Log(TAG, "start");

        this.backupVolume(this.getCurrentVolume());

    this.stopUntilScreenOff = false;

        AudioFocusUtility.request(this.audioManager, logger);
    }

}
```

```java
private void backupVolume(int volume) {
    if (!IsLive) return;

    DiagnosticsLogger logger = Logger;
    this.beforeVolume = volume;
    if (logger != null) logger.Log(TAG, "beforeVolume: " + volume);
}

private void restoreVolume() {
    if (!IsLive) return;

    DiagnosticsLogger logger = Logger;
    if (logger != null) logger.Log(TAG, "restoreVolume");

    if (this.beforeVolume >= 0) {
        if (logger != null) logger.Log(TAG, "restore volume: " + this.beforeVolume);
        this.setVolumeTo(this.beforeVolume, AudioManager.FLAG_SHOW_UI);
        this.beforeVolume = -1;
    }
}
```

### `ForegroundServiceFailureTest.java`

API 31以降のandroidTestでoperationを拒否例外へ差し替える。各test後は `@After` で必ずdefaultへ戻す。

```java
@RunWith(AndroidJUnit4.class)
@SdkSuppress(minSdkVersion = 31)
public final class ForegroundServiceFailureTest {
    @After
    public void tearDown() {
        Context context = InstrumentationRegistry.getInstrumentation().getTargetContext();
        context.stopService(new Intent(context, DNSService.class));
        context.getSharedPreferences("dns_service_state", Context.MODE_PRIVATE)
                .edit()
                .clear()
                .commit();
        Compat.resetForegroundOperationsForTest();
        DNSService.IsLive = false;
    }

    @Test
    public void startRequestRejectionReturnsFalse() {
        Context context = InstrumentationRegistry.getInstrumentation().getTargetContext();
        Compat.setForegroundServiceStartOperationForTest((ignoredContext, ignoredIntent) -> {
            throw new ForegroundServiceStartNotAllowedException("forced start request rejection");
        });

        assertFalse(Compat.tryStartForegroundService(
                context,
                new Intent(context, DNSService.class).setAction(DNSService.ACTION_START)));
    }

    @Test
    public void rejectedPromotionDoesNotClearSavedState() {
        Context context = InstrumentationRegistry.getInstrumentation().getTargetContext();
        SharedPreferences state =
                context.getSharedPreferences("dns_service_state", Context.MODE_PRIVATE);
        state.edit()
                .putBoolean("enabled", true)
                .putBoolean("stopUntilScreenOff", true)
                .putLong("disableTime", 123456789L)
                .commit();

        AtomicBoolean attempted = new AtomicBoolean();
        Compat.setForegroundPromotionOperationForTest((service, id, notification) -> {
            attempted.set(true);
            throw new ForegroundServiceStartNotAllowedException("forced promotion rejection");
        });

        context.startForegroundService(
                new Intent(context, DNSService.class).setAction(DNSService.ACTION_REBOOT));
        waitUntil(attempted::get, 5000);
        waitUntil(() -> !isServiceRunning(context), 5000);

        assertTrue(attempted.get());
        assertFalse(DNSService.IsLive);
        assertFalse(isServiceRunning(context));
        assertTrue(state.contains("enabled"));
    }

    @Test
    public void rebootNotificationFailureDoesNotThrow() {
        Context context = new ThrowingNotificationContext(
                InstrumentationRegistry.getInstrumentation().getTargetContext());
        assertFalse(DNSReceiver.tryShowRebootNotification(context));
    }

    private static void waitUntil(Condition condition, long timeoutMilliseconds) {
        long deadline = SystemClock.uptimeMillis() + timeoutMilliseconds;
        while (!condition.evaluate() && SystemClock.uptimeMillis() < deadline) {
            SystemClock.sleep(50);
        }
    }

    @SuppressWarnings("deprecation")
    private static boolean isServiceRunning(Context context) {
        ActivityManager manager = Compat.getSystemService(context, ActivityManager.class);
        if (manager == null) return false;
        ComponentName target = new ComponentName(context, DNSService.class);
        for (ActivityManager.RunningServiceInfo info : manager.getRunningServices(Integer.MAX_VALUE)) {
            if (target.equals(info.service)) return true;
        }
        return false;
    }

    private interface Condition {
        boolean evaluate();
    }

    private static final class ThrowingNotificationContext extends ContextWrapper {
        ThrowingNotificationContext(Context base) {
            super(base);
        }

        @Override
        public int checkSelfPermission(String permission) {
            return PackageManager.PERMISSION_GRANTED;
        }

        }
```

`waitUntil()` は期限付きpollだけに使い、無期限sleepや本番コードへの通知用test flagは追加しない。

## 対象ファイル

| ファイル | 変更内容 |
| --- | --- |
| `Compat.java` | 起動要求と前景化の安全なラッパー、debug test用operationを追加 |
| `IntentUtility.java` | 起動結果をbooleanで返し、Tile非稼働更新を共通化 |
| `DNSReceiver.java` | Boot・更新後の状態同期と例外非送出の復旧通知を追加 |
| `DNSService.java` | 早期前景化、callbackガード、通知更新分離、失敗時停止、Alarm・状態保持を整合 |
| `ForegroundServiceFailureTest.java` | 起動要求拒否、前景化拒否、通知失敗を強制するandroidTestを追加 |

Manifest、Gradle設定、Foreground Serviceタイプ、権限宣言は変更しない。

## 対象外

- Foreground ServiceをWorkManagerなどへ置き換えること
- `specialUse` 以外のForeground Serviceタイプへの変更
- Alarm用 `PendingIntent.getService()` の `getForegroundService()` への移行
- 通知クラス全体のリファクタリング
- Foreground Service以外の監査項目の修正

Alarm用PendingIntentの種類を変えると、更新前に登録済みのAlarmを明示的に移行・解除する必要が
あるため、今回のクラッシュ修正とは分離する。AlarmからServiceが起動した後の前景化拒否は、
今回追加するService側の処理で安全に停止できる。

## 実装時の書式

既存ソースの書式に合わせ、短いガード節、ログ、単純なメソッド呼び出しは1行に保つ。
Builderチェーンや引数が長い呼び出しだけを改行し、機械的に1引数ずつ改行しない。
既存コードと無関係な整形は行わない。
