# テスト方針

## 変更ごとの基本確認

Androidコード変更では、影響に応じて次を実行する。

1. Debug APKビルド
2. androidTestのコンパイル
3. Android Lint
4. API 21でのインストール確認
5. 影響対象APIでの機能確認
6. UI変更時のスクリーンショット比較

スクリプト変更ではTypeScript型チェックを実行する。依存関係変更時はnpm監査も行う。

## 自動テスト

現在のandroidTestは次を提供する。

- `SmokeTest`: instrumentation、shell command、スクリーンショット保存の疎通確認
- `ScreenshotTest`: 主要画面のスクリーンショット取得

サービス状態、権限拒否、例外経路を検証するUnit Testは存在しない。この不足は
[AUD-008](../問題管理/問題一覧.md#aud-008-サービスの自動テストが不足している)で管理する。

## CI

現在のGitHub Actionsはrelease bundleのビルドを中心とし、Lint、Unit Test、androidTest、
TypeScript型チェックを品質ゲートとして実行していない。Lint自体も既知エラーにより失敗するため、
まず[AUD-007](../問題管理/問題一覧.md#aud-007-lintを品質ゲートにできない)を解消する。

## 画面確認

UI変更は[スクリーンショットテスト](スクリーンショットテスト.md)に従い、API、ロケール、
ナビゲーション、テーマの必要な組み合わせを比較する。
