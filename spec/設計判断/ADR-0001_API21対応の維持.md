# ADR-0001 API 21対応の維持

## 状況

DoNotSpeakはAndroid 5.0以降を動作対象としている。新しいAGPやAndroid APIは最低APIを上げることで
単純化できるが、既存ユーザーの対応範囲を狭める。

## 決定

`minSdk = 21`を維持する。新しいAPIは`Build.VERSION.SDK_INT`分岐または`Compat`へ隔離し、
API 21でのクラスロード、インストール、基本動作を検証する。

## 理由

- READMEでAndroid 5.0以降を対応環境として公開している
- API 21エミュレータでインストールと基本画面を検証できる
- 現時点で最低APIを上げなければ実現できない必須機能がない

## 影響

- D8 API modelingが生成する`android.*`クラスをAPKへ含めない設定が必要
- API別の実装分岐とLint抑止理由を維持する必要がある
- 出荷前にAPI 21のインストール確認を必須とする
