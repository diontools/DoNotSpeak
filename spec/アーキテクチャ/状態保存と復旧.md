# 状態保存と復旧

## ユーザー設定

`donotspeak_pref.xml`には、ユーザーが選択した動作設定とBluetooth機器アドレスを保存する。
これらは`PreferenceBackupAgent`を通じてAndroid Backupの対象とする。詳細は
[設定項目](../製品仕様/設定項目.md)を参照する。

## サービス状態

`dns_service_state`には、サービス再作成後の復旧に必要な状態を保存する。

| キー | 内容 |
| --- | --- |
| `enabled` | 保護が有効か |
| `stopUntilScreenOff` | 画面消灯まで一時停止中か |
| `disableTime` | 時刻指定の復帰時刻。未指定は0 |

状態変更時は保存後に音量、Alarm、通知、Tileを更新する。sticky再作成やアプリ更新では保存状態を
読み戻す。保存値がない場合は保護有効を既定とする。

## 一時停止Alarm

時刻指定の一時停止ではRTC Alarmを設定し、期限到達時に`START`を送る。状態更新時には既存Alarmを
解除してから必要なAlarmだけを再設定する。

## 定期確認

サービス稼働中は定期確認Alarmを設定し、サービス停止を検出した場合に復旧通知を試みる。
初回発火時刻の現行不具合は[AUD-005](../問題管理/問題一覧.md#aud-005-定期確認alarmの初回時刻が誤っている)で管理する。

## 状態を削除する条件

保存状態の削除はユーザーの明示停止が成立した場合に限定する。現行実装では`onDestroy()`で常に
削除するため、Foreground Service対応と同時に[AUD-001対応計画](../対応計画/AUD-001_フォアグラウンドサービス起動失敗.md)
に従って修正する。
