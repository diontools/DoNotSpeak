# サービスライフサイクル

## 構成要素

| 要素 | 責務 |
| --- | --- |
| `MainActivity` | 権限確認、開始、一時停止、設定・診断画面への入口 |
| `DNSService` | 音量監視、接続判定、状態保存、通知、Alarm |
| `DNSReceiver` | 端末起動、アプリ更新、定期確認の受信 |
| `DNSTileService` | Quick Settings Tileの操作と状態表示 |
| `IntentUtility` | 各入口から`DNSService`へコマンドを送る |
| `Compat` | Android APIレベル差の隔離 |

## コマンド

`DNSService.onStartCommand()`は次のコマンドを処理する。

| コマンド | 目的 |
| --- | --- |
| `START` | 保護を開始する |
| `STOP` | 指定時刻まで一時停止する |
| `STOP_UNTIL_SCREEN_OFF` | 画面消灯まで一時停止する |
| `SWITCH` | 保護状態を切り替える |
| `APPLY_SETTINGS` | 設定を再読込して状態を更新する |
| `REBOOT` | 保存状態を復元する |
| `SHUTDOWN` | ユーザーの確認後にサービスを終了する |

sticky再作成でIntentがない場合は`REBOOT`として保存状態を復元する。

## 前景化

Android 8以降は`startForegroundService()`で起動し、サービス側でステータス通知を使って前景化する。
前景化の成功前に音量、Alarm、保存状態を変更しないことを目標とする。

現行実装はForeground Service起動・前景化拒否を処理していない。修正方針と完了条件は
[AUD-001対応計画](../対応計画/AUD-001_フォアグラウンドサービス起動失敗.md)を参照する。

## 終了

ユーザーの明示停止だけを、保存済み保護状態を破棄する操作として扱う。OSによる終了、起動拒否、
予期しないライフサイクル終了では、復旧に必要な状態を保持する。`IsLive`とTile表示は実際の
サービス稼働状態に一致させる。
