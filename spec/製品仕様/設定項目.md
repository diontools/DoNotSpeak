# 設定項目

設定は`donotspeak_pref.xml`へ保存し、Android Backupの対象とする。

| 設定 | 既定値 | 動作 |
| --- | --- | --- |
| 音量を復元 | 無効 | 保護を一時停止したとき、記録済みの音量へ戻す |
| 再生停止を要求 | 無効 | 保護開始時に一時的なAudio Focusを要求する |
| 画面を点灯状態に保つ | 無効 | 一時停止中にWakeLockを保持する |
| 音量を段階調整 | 無効 | `setStreamVolume`ではなく段階的な音量調整を使う |
| Bluetoothを使用 | 有効 | OS権限がある場合、許可されたBluetooth機器をイヤホンとして判定する |
| 接続時に音量を復元 | 無効 | イヤホン接続を検出したとき記録済み音量へ戻す |
| 診断ファイルログ | 無効 | 外部キャッシュへ診断ログを書き出す |
| Bluetooth機器一覧 | 空 | イヤホンとして扱うペアリング済み機器のアドレスを保持する |
| 一時停止方法 | 画面消灯まで | ダイアログで前回選択した停止方法を保持する |
| 分数選択値 | 5分 | ダイアログで前回選択した5分刻みの値を保持する |

## 通知設定表示

Android 13以降の設定画面は、アプリ通知、ステータス通知チャンネル、復旧通知チャンネルの実状態を
表示する。通知権限が未許可の場合は権限を要求でき、許可済みの場合はOSの通知設定を開ける。
OSの通知設定から戻った場合は実状態を再取得して表示を更新する。ステータス通知の再表示は設定画面の
復帰処理ではなく、稼働中サービスが通知ブロック状態変更Broadcastを受信した時点で行う。
`USE_NOTIFICATION`は起動時に権限を要求する意向を保持する内部値であり、通知表示のON/OFF設定として
ユーザーへ公開しない。実機確認の残件は
[AUD-004](../問題管理/問題一覧.md#aud-004-通知設定と実動作が一致しない)で管理する。

「Bluetoothを使用」の保存値とOSのBluetooth権限は別々に管理する。Android 12以降で権限を
利用できない場合は、保存値が有効でもBluetooth判定を無効として扱う。この場合は音漏れ防止を
優先し、Bluetooth機器を接続中と判定できないことで音量が0になってもよい。実機検証の残件は
[AUD-003](../問題管理/問題一覧.md#aud-003-bluetooth権限不足時に初期化を待ち続ける)で管理する。
