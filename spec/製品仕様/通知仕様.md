# 通知仕様

## ステータス通知

フォアグラウンドサービス稼働中は、Androidの要件に従ってステータス通知を作成する。

- 保護中はミュート状態と「画面消灯まで停止」操作を表示する
- 一時停止中は復帰条件と「メニューを表示」操作を表示する
- 通知タップは現在状態に応じて一時停止ダイアログまたは再開操作へ接続する
- 通知は継続通知、低優先度、ロック画面公開として扱う

## 復旧通知

定期確認でサービス停止を検出した場合は、ユーザー操作で再起動できる復旧通知を表示する。
Android 13以降で通知権限がない場合や通知チャンネルが無効な場合、表示はbest effortとし、
通知失敗によってプロセスをクラッシュさせない。

## 通知権限

`POST_NOTIFICATIONS`の拒否は、フォアグラウンドサービス自体を通知なしの通常サービスへ変更する
根拠にはしない。Android 13以降の設定画面は、アプリ通知、ステータス通知チャンネル、復旧通知
チャンネルの実状態を区別して表示する。通知権限が未許可の場合は権限を要求でき、許可済みの場合は
OSの通知設定を開ける。

API 28以降では、稼働中のサービスがアプリ通知または通知チャンネルのブロック状態変更Broadcastを
受信する。アプリ通知またはステータス通知チャンネルが表示可能になった場合は、保存設定を再適用せず、
現在状態のステータス通知を直接再発行する。復旧通知チャンネルだけの変更では再発行しない。
設定画面の`onResume()`は通知状態の表示更新だけを行う。

`USE_NOTIFICATION`は起動時に通知権限を要求する意向を保持する内部値であり、ステータス通知と復旧通知の
生成可否には使用しない。設定画面から権限要求を明示的に開始した場合は、この値を有効にして要求する。

設定UIの実機確認は[AUD-004](../問題管理/問題一覧.md#aud-004-通知設定と実動作が一致しない)、
起動拒否時の復旧通知は[AUD-001](../問題管理/問題一覧.md#aud-001-フォアグラウンドサービス起動失敗)で管理する。
